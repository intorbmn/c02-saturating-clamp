# C02 Saturating Clamp 8-bit

RTL-to-GDSII project implementing an 8-bit saturating clamp circuit.

## Project structure

- `rtl/`: Verilog RTL source
- `tb/`: testbenches
- `sim/`: simulation scripts and results
- `synth/`: synthesis scripts, netlists, and reports
- `openlane/`: OpenLane configuration and physical-design results

## Tools

- Icarus Verilog
- Yosys
- OpenLane
- Sky130 PDK
